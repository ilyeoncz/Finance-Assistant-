# Finance-Assistant-
The Personal Finance Assistant is an interactive user friendly built with Python, Pandas, and Gradio, using a Gemini API key. The purpose is to help users track everyday expenses, to help monitor the monthly budget while also giving feedback to track and improve budgeting 

The key features are the customisable colour theme and the automatic classification of minimal moderate and high expenses. Other key features are the automatic AI analysis and the option to reset the budget or download the CSV report. \

How to Run It: 
1.	Upload and open your project notebook. 
2.	Execute the Code: Run all cells sequentially from top to bottom. 
3.	Choose a Colour: When prompted in the terminal output, choose a UI colour from the four options of green blue rose or violet 
4.	Launch the Gradio link and input the required info 

Sample Input and Output: 

Sample Input: 

Expense Description: Groceries 

Amount: $120.00

Category: Food & Dining

Monthly Budget: $500.00

Sample Output:

Summary Box: 

Budget Overview:
